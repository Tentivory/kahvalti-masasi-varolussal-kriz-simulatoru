# Kahvaltı Masası Varoluşsal Kriz Simülatörü

Bu proje, insanlığın en büyük sorunu olan "kahvaltıda peynir yerken aniden 'ben neden buradayım?' diye düşünme" krizini bilimsel kesinlikle simüle eder.

## Neden Bu Proje?

Çünkü sabah 7'de ekmek kırarken evrenin anlamını sorgulamak artık norm haline geldi. Biz de bunu kodladık. Ciddiyetle.

## Nasıl Çalışır?

1. `python kriz.py` yaz
2. Kahvaltı masana otur
3. Krizi yaşa
4. Asla bitmez, tıpkı gerçek hayattaki gibi

## Özellikler

- Sonsuz döngü (evren gibi)
- Rastgele Türkçe varoluşsal cümleler
- Dramatik bekleme süreleri
- Patates içermez (söz verdik)

## Uyarı

Bu scripti çalıştırdıktan sonra hayata bakışınız değişebilir. Değişmezse de sorun yok, zaten hiçbir şey değişmiyor.
